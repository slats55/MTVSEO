# Agent Brain — Decisions

This folder stores architectural and process decisions made during the project lifecycle.

## Purpose

When a significant decision is made (e.g., "we will use SQLAlchemy async throughout"), document it here with:
- **What** was decided
- **Why** that approach was chosen
- **Alternatives considered**
- **Date** and **decision maker**

## Naming

Use a descriptive title: `YYYY-MM-DD-descriptive-title.md`

Example: `2025-05-12-obsidian-brain-structure.md`

## Maintenance

- Do not delete or revise decision records — add new decisions if the approach changes
- Decisions are historical record; they document what was decided, not what should be done now
