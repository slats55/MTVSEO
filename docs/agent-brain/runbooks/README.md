# Runbooks

This folder stores repeatable procedure documentation — step-by-step guides for common tasks.

## Purpose

When you find yourself repeating a multi-step procedure:
1. Document it as a runbook here
2. Name it descriptively: `runbook-<topic>.md`
3. Include prerequisites, exact commands, expected outputs, and troubleshooting

## Example Runbook Topics

- How to run the full verification suite
- How to add a new API endpoint
- How to inspect Docker logs
- How to run a specific test file

## Formatting

Use clear numbered steps. Include:
1. **Prerequisites** (what must be true before starting)
2. **Steps** (exact commands with expected output)
3. **Verification** (how to confirm success)
4. **Troubleshooting** (common failure modes)
